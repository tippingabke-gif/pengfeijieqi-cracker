# 1.2.0 修复与验证

## 根因及处理

原生推理在 RVA `0xc5a400` 已正确得到类别和原始分数；`0xcc1c30 → 0x1182c0` 数值往返后，结果对象 `+0x1c` 却变为 `0xff800000`（单精度负无穷）。阈值随后拒绝所有棋子，将帅预匹配返回0，导致空棋盘和 `Lack red king`。

在 `0xc5a61a` 完整结果返回点，仅对非有限分数字段恢复原始输出中的真实 argmax 值。要求19项原始值全部有限、数组长度有效、类别索引一致、标签有效。没有固定高分、softmax或虚构棋子；标签、原始列表及判定阈值不变。

原始阈值：暗子12.0，其他棋子7.0；其他棋子相对blank类别17的分差还需大于7.0。将帅校验保留。此前已验证的拟合配置、数字标签适配和几何矩形保留同时整合。
